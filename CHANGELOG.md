# Changelog

## 0.1.8

Initial public release.

- KidsWatch account configuration through the Home Assistant UI.
- Automatic stable `m2` client identifier.
- Associated-watch discovery.
- GPS device tracker, battery, steps, coordinates, address, last-location and GPS-accuracy entities.
- Manual fresh-position request button with timestamp-aware polling.
- 60-second cloud polling.
- French and English configuration translations.
- Production-safe logging with sensitive API payloads removed.
